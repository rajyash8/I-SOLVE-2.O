# I-SOLVE 2.0 – Hackathon Landing Page

## Overview

I-SOLVE 2.0 is a responsive hackathon landing page developed to promote and manage the I-SOLVE hackathon event. The website provides participants with essential information about the event, registration process, schedule, themes, prizes, and event guidelines through an engaging and modern user interface.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and interactive user interface
* Event information and overview
* Registration section
* Timeline and schedule display
* Prize and reward information
* Sponsor and organizer showcase
* Smooth navigation and user-friendly layout

## Technologies Used

* HTML5
* CSS3
* JavaScript
